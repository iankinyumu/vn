4. 5. Make the chart readable like a trading chart: add a thin crosshair that follows pointer movement and shows the inspected price, plus a horizontal line and price marker for the latest tick. Add a right-side vertical price axis with readable tick labels based on the visible price range. The labels and latest-price marker must update as prices fluctuate, use the selected index's decimal precision, and remain aligned with the plotted line after resize or index changes. Keep these additions lightweight so they do not undo the chart speed improvement.
6. Add or update focused tests for the visible UI and graph behavior, run the relevant tests and `npm test`, and report any limitation that requires a live feed or browser. Do not alter unrelated pages or the crypto spot module. Do not read environment secrets. Do not modify or delete existing untracked files.

Acceptance: one contract selector, no practice ribbon, no “Trade digit contracts” copy in the page, one clear virtual balance, a stable 0–9 digit row with the current digit highlighted, and a visibly responsive chart with a pointer crosshair, latest-price line, right-side price labels, correct latest point, and no feed regression.
