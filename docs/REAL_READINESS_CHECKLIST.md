# Real readiness checklist v1 (draft, unpublished)

This is a draft only. It must be published as an immutable database checklist by an authorized operator before any future Real work begins. `enable_real_accounts` accepts only the latest published version and requires a reference—not free text—for every key below.

| Key | Required evidence |
| --- | --- |
| `seed_custody` | Real seed generation and custody outside this database |
| `funding_reconciliation` | Implemented, reconciled, load-tested Real funding |
| `real_policy` | Reviewed and published Real policy limits |
| `step_up_authentication` | Step-up authentication for Real account use |
| `conformance_parity` | Green conformance and parity suite against a Real-shaped fixture |
| `owner_signoff` | Named Owner approval |

Each value must be a PR URL, report URL, `PR-<number>`, or `run:<id>`. Practice does not satisfy any of these Real-only gates.
